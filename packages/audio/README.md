# @ifloom/audio

The IFLoom audio player: `startAudio(runner)` plays the music and sounds a game's view lists, in the browser, with plain `HTMLAudioElement`s and no framework. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/audio
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you. The React UI starts it for you.

## Docs

- [The audio player](https://ifloom.dev/docs/reference/browser/audio-player) explains `startAudio` and its options.
- [API](https://ifloom.dev/docs/api/audio) lists every export with its signature and fields.

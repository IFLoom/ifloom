# @ifloom/browser

Browser helpers for IFLoom games, in plain DOM for any UI: a runner with saves and an autosave, save drivers for `localStorage` and IndexedDB, the clock that runs timers and minigames, and keyboard shortcuts. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/browser
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you.

## Docs

- [Browser helpers](https://ifloom.dev/docs/reference/browser) explains each helper.
- [API](https://ifloom.dev/docs/api/browser) lists every export with its signature and fields.

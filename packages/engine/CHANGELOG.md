# @ifloom/engine

## 0.2.0

### Minor Changes

- [#18](https://github.com/IFLoom/ifloom/pull/18) [`32e8cba`](https://github.com/IFLoom/ifloom/commit/32e8cba62ecf34b57a17198ae5c35a26604d7ec9) Thanks [@ianleckey](https://github.com/ianleckey)! - Removed: `PartnerQueries` from `@ifloom/engine/plugin`, so the engine no longer names any plugin. A plugin of your own that asks a first-party plugin's query without importing it gives the answer's type, as in `query<{ day: number }>('calendar/now')`. A game that imports the calendar, places or the cast still reads their queries typed.

- [#21](https://github.com/IFLoom/ifloom/pull/21) [`826af8c`](https://github.com/IFLoom/ifloom/commit/826af8c012a8a27939b8ffd1bdf2f454494f5308) Thanks [@ianleckey](https://github.com/ianleckey)! - Removed: holding is no longer the engine's (ADR 0016). `state.held`, `view.held`, an entity's `at`, the `entity` and `move` effects, `at` and ranges on the `entity` condition, `at` on a `Select` and `units` on `count`, `create`'s `at`, `carryOver.held`, and the exports `give`, `take`, `move`, `holding`, `heldBy`, `heldCount`, `holderOf`, `canHold`, `Holder`, `Placement` and `HeldView` are gone. A game keeps things in kv keys, or with a plugin that keeps them, such as the inventory or the wardrobe.

- [#20](https://github.com/IFLoom/ifloom/pull/20) [`91fafc8`](https://github.com/IFLoom/ifloom/commit/91fafc8ec46e65c795bc90a449cd29cbd1e46429) Thanks [@ianleckey](https://github.com/ianleckey)! - Changed: the `you` effect and `state.you` belong to the player feature, not holdings, and the checker reads its target as a `{ protagonist }` reference, with its own problems: `unknown protagonist "…"` and `"…" can't be played: its kind "…" isn't unique`. The holder reference no longer takes `protagonist`.

- [#21](https://github.com/IFLoom/ifloom/pull/21) [`826af8c`](https://github.com/IFLoom/ifloom/commit/826af8c012a8a27939b8ffd1bdf2f454494f5308) Thanks [@ianleckey](https://github.com/ianleckey)! - Added: the `receive` and `release` effects and the `owned` condition, which hand things to the plugins that keep them in the order of the game's new `receivers` list, and do nothing in a game with none: `{ receive: 'clothing:shirt' }`, `{ release: 'food:coffee', by: 2 }`, `{ owned: 'food:coffee', gte: 1 }`. A plugin keeps things with its new `receiver`, and carries its state into a New Game+ with its new `carry`. A `create` runs its own `effects` with `'$'` as the new entity, such as `[{ receive: '$' }]`. `ownedCount`, `receiveThing`, `releaseThing`, `receiversOf`, `Someone`, `Played` and `resolveYou` (which replaces `resolveHolder`) are exported, and `everyEntity` and `hasEntity` from `@ifloom/engine/plugin`. `arg.holder()` is now `arg.someone()`.

### Patch Changes

- [#14](https://github.com/IFLoom/ifloom/pull/14) [`e54da5e`](https://github.com/IFLoom/ifloom/commit/e54da5ec92e8a25be26633eb7fb7e1a1b7f46c67) Thanks [@ianleckey](https://github.com/ianleckey)! - Added: `credits` in content, groups of the people and sources a game thanks (the team, patrons, photographs, models), each credit with a `name` and an optional `role`, `description`, `href`, `licence` and `art`. Groups merge by id, so a mod can credit itself, and the checker reports a credit with no name or a link that isn't `http(s):` or `mailto:`. `creditsOf(game)` lists the groups that have credits.

- [#19](https://github.com/IFLoom/ifloom/pull/19) [`7d00d9f`](https://github.com/IFLoom/ifloom/commit/7d00d9f0a8a4c4931aa40fbde0bd2d1b5ade0a13) Thanks [@ianleckey](https://github.com/ianleckey)! - Removed: every upgrade step for saves, packs and command logs from before this release. `SAVE_VERSION` and `SCHEMA` start again at 1, and each first-party plugin's state, content and command versions are 1 with no migrations. A save, pack or log from an earlier release is refused instead of carried forward. The machinery stays: the engine's step tables, a plugin's `migrations`, `contentMigrations` and `commandMigrations`, and the game's own `rules.migrations` work as before. `ContentTools.effects` and `PackContext`'s `entities` and `you`, which only the removed steps used, are gone, and a pack that records no version for a plugin is read as written for the plugin's current version.

- [#17](https://github.com/IFLoom/ifloom/pull/17) [`69f8b2d`](https://github.com/IFLoom/ifloom/commit/69f8b2d1b9b013df0d3363e78b2a3a8e04d78fb5) Thanks [@ianleckey](https://github.com/ianleckey)! - Fixed: every library package declares `sideEffects` (`false`, and only its CSS for `@ifloom/react`), so a bundler drops the modules a game never uses. Importing `@ifloom/react/styles.css` and the themes is kept.

- [#20](https://github.com/IFLoom/ifloom/pull/20) [`91fafc8`](https://github.com/IFLoom/ifloom/commit/91fafc8ec46e65c795bc90a449cd29cbd1e46429) Thanks [@ianleckey](https://github.com/ianleckey)! - Added: a `value` condition, which compares a plugin's or the game's value by name the way `kv` compares a key, with `is`, a range, or neither: `{ value: 'messages/unread', with: { channel: 'texts' }, gte: 1 }`. A value nobody declares never holds.

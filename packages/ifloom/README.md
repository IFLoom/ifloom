# ifloom

The `ifloom` command, so `npx ifloom` runs IFLoom's command line without installing anything first. It runs [`@ifloom/cli`](https://www.npmjs.com/package/@ifloom/cli). It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Use

```sh
npx ifloom help
```

A game lists `@ifloom/cli` as a dev dependency instead, so its version is the one the game chose.

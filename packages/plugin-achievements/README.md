# @ifloom/plugin-achievements

Achievements for IFLoom: earned by conditions or effects, with secret ones and progress counts, and kept in the player's profile across saves. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/plugin-achievements
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you. Its React UI is the `@ifloom/plugin-achievements/react` subpath, for a game that renders with `@ifloom/react`.

## Docs

- [Achievements](https://ifloom.dev/docs/reference/plugins/achievements) explains the plugin, its content and its view.
- [API](https://ifloom.dev/docs/api/plugin-achievements) lists every export with its signature and fields.

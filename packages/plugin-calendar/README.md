# @ifloom/plugin-calendar

A calendar for IFLoom: the periods of a day, the days of a week, sleep and a curfew, and what a turn is. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/plugin-calendar
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you. Its React UI is the `@ifloom/plugin-calendar/react` subpath, for a game that renders with `@ifloom/react`.

## Docs

- [Calendar](https://ifloom.dev/docs/reference/plugins/calendar) explains the plugin, its content and its view.
- [API](https://ifloom.dev/docs/api/plugin-calendar) lists every export with its signature and fields.

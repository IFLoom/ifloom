# @ifloom/plugin-cast

A cast for IFLoom: characters with schedules, who is in the room, talking and calling, and relationships as stats the game declares. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/plugin-cast
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you. Its React UI is the `@ifloom/plugin-cast/react` subpath, for a game that renders with `@ifloom/react`.

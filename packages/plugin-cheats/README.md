# @ifloom/plugin-cheats

Cheats for IFLoom: a panel of effects the player can use at any time, free for everyone or refused until a condition (a supporter unlock, say) holds, with a log of what was used. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/plugin-cheats
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you. Its React UI is the `@ifloom/plugin-cheats/react` subpath, for a game that renders with `@ifloom/react`.

## Docs

- [Cheats](https://ifloom.dev/docs/reference/plugins/cheats) explains the plugin, its content and its view.
- [API](https://ifloom.dev/docs/api/plugin-cheats) lists every export with its signature and fields.

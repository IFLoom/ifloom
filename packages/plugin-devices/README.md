# @ifloom/plugin-devices

Devices for IFLoom: a phone, a laptop or a desk drawer, with apps the game declares, badges, and opening one without leaving the room. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/plugin-devices
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you. Its React UI is the `@ifloom/plugin-devices/react` subpath, for a game that renders with `@ifloom/react`.

## Docs

- [Devices](https://ifloom.dev/docs/reference/plugins/devices) explains the plugin, its content and its view.
- [API](https://ifloom.dev/docs/api/plugin-devices) lists every export with its signature and fields.

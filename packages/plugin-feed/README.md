# @ifloom/plugin-feed

Feeds for IFLoom: timelines of posts that appear when the story allows, the player's own posts, and the reactions they get. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/plugin-feed
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you. Its React UI is the `@ifloom/plugin-feed/react` subpath, for a game that renders with `@ifloom/react`.

## Docs

- [Feed](https://ifloom.dev/docs/reference/plugins/feed) explains the plugin, its content and its view.
- [API](https://ifloom.dev/docs/api/plugin-feed) lists every export with its signature and fields.

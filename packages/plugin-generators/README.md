# @ifloom/plugin-generators

Generators for IFLoom: named pools of values and templates that make new entities from them, seeded and replay-exact. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/plugin-generators
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you.

## Docs

- [Generators](https://ifloom.dev/docs/reference/plugins/generators) explains the plugin, its content and its view.
- [API](https://ifloom.dev/docs/api/plugin-generators) lists every export with its signature and fields.

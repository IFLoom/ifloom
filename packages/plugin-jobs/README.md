# @ifloom/plugin-jobs

Jobs for IFLoom: hiring requirements, shifts that cost time or energy and pay a wage, promotion ladders, and getting fired. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/plugin-jobs
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you. Its React UI is the `@ifloom/plugin-jobs/react` subpath, for a game that renders with `@ifloom/react`.

## Docs

- [Jobs](https://ifloom.dev/docs/reference/plugins/jobs) explains the plugin, its content and its view.
- [API](https://ifloom.dev/docs/api/plugin-jobs) lists every export with its signature and fields.

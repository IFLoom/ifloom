# @ifloom/plugin-messages

Messages for IFLoom: threads of messages that arrive when the story allows, and replies that are choices. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/plugin-messages
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you. Its React UI is the `@ifloom/plugin-messages/react` subpath, for a game that renders with `@ifloom/react`.

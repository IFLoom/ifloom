# @ifloom/plugin-quests

Quests for IFLoom: what the player is doing, how far they have got, and the hint for what comes next. It is part of [IFLoom](https://ifloom.dev), an interactive fiction engine whose games build to one HTML file that opens from disk.

## Install

```sh
npm install @ifloom/plugin-quests
```

It needs `@ifloom/engine` as a peer, which npm 7 and later installs for you. Its React UI is the `@ifloom/plugin-quests/react` subpath, for a game that renders with `@ifloom/react`.

## Docs

- [Quests](https://ifloom.dev/docs/reference/plugins/quests) explains the plugin, its content and its view.
- [API](https://ifloom.dev/docs/api/plugin-quests) lists every export with its signature and fields.
